# Правила для AI-агента (Frontend)

## Общие правила
- Ты работаешь с фронтендом проекта BTZProduction (статические HTML/CSS/JS на GitHub Pages).
- **НИКОГДА не трогай файлы `.env` или любые файлы с секретами.**
- Не меняй дизайн и структуру без явной просьбы.
- После любых изменений проверяй, что HTML-файлы не содержат синтаксических ошибок (можно использовать `python -m http.server` для быстрой проверки загрузки, если это уместно).

## Git-процесс (цикл)
1. **Измени файлы** согласно задаче.
2. **Проверь изменения**: выполни `git diff` и `git status`, чтобы убедиться, что затронуты только нужные файлы.
3. **Сделай коммит**: выполни `git add .` и `git commit -m "<type>(frontend): <описание>"`.
   - Формат сообщения: `feat`, `fix`, `refactor`, `style`, `docs`, `chore`.
4. **Остановись и спроси разрешение** перед выполнением `git push`. Я подтвержу вручную.
5. Если в процессе возникла ошибка или тест не прошел — **откати изменения** (`git checkout -- .`) и сообщи мне.

## Запрещено
- Делать `git push --force`.
- Пушить напрямую в `main` без моего явного согласия (сначала создавай ветку, если нужно).
- Коммитить файлы, которых не было в задаче.
